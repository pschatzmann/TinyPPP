◆ TINYPPP_RX_BUFFER

#define TINYPPP_RX_BUFFER   512

ESP32 implementation (arduino-esp32 3.x): uses the PPP support of the ESP-IDF lwIP via esp_netif with a custom I/O driver that reads and writes an Arduino Stream. TinyPPP is a NetworkInterface, so NetworkClient, NetworkServer, NetworkUDP, Network.onEvent() (ARDUINO_EVENT_PPP_*) and Network.hostByName() work as with WiFi or Ethernet.

ESP-IDF runs PPP in client mode: the peer (e.g. Linux pppd) must assign the IP addresses.

Note: TinyPPP uses the PPP interface slot of the Network library, so it can't be combined with the PPP (modem) library of the core.
