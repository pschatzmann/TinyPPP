Detailed Description

template<size_t MAX_FRAME>
class tinyppp::HDLCDecoder< MAX_FRAME >

HDLC frame decoder (RFC 1662).

Reassembles frames from a byte stream. After a complete frame with a valid FCS has been received, add() returns true and frame()/frameLen() give the content (address/control removed when present, FCS removed).
