◆ TINYPPP_MRU

#define TINYPPP_MRU   1500

A small, portable PPP implementation (RFC 1661 LCP, RFC 1332 IPCP, RFC 1334 PAP client, RFC 1877 DNS options) that runs over any Arduino Stream. It does not contain an IP stack: received IPv4 packets are handed to onIPv4Packet() and outgoing packets are passed to sendIPv4() or beginIPv4()/writeIPv4()/endIPv4().

The engine is not thread safe: the caller must serialize process() and the send methods (e.g. by holding the lwIP lock).
