Detailed Description

PPP network interface for platforms without lwIP: the PPP engine combined with the TinyPPP IPStack (TCP, UDP, ICMP echo and DNS).

Generic implementation for platforms without lwIP: SAMD and mbed based WiFiNINA boards (Nano 33 IoT, MKR WiFi 1010, Nano RP2040 Connect), the desktop (Arduino-Emulator) and other cores.

The PPP engine is combined with the small TinyPPP IPStack, so PPPClient, PPPServer and PPPUDP work over the link. Received IPv4 packets that are not handled by the stack can be processed with onReceive(), and raw packets can be sent with send().

There is no background task: the link is processed by all socket methods and by loop(). Call loop() regularly when the sketch does not use a socket for a while.
