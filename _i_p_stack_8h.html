A minimal IPv4 stack for platforms without lwIP (e.g. SAMD and mbed based WiFiNINA boards, the desktop): ICMP echo, UDP, TCP and a DNS resolver. It is independent from PPP: the link layer implements ipBegin(), ipWrite(), ipEnd() and ipPoll() and passes received packets to ipInput().

Limitations (by design, to keep it small):

  • TCP accepts in-order segments only and has no congestion control
  • no IP fragmentation and reassembly, no IP options on output
  • no IPv6, no multicast

There is no background task: the stack is processed in ipPoll(), which is called by all socket methods. Call it regularly (e.g. TinyPPP::loop()) when the sketch is busy with something else.
