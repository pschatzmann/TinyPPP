RP2040 / RP2350 (Earle Philhower arduino-pico core) implementation.

The core's lwIP is built without PPP support, so the TinyPPP engine is used and registered as a point-to-point lwIP netif. All lwIP based Arduino classes of the core (WiFiClient, WiFiServer, WiFiUDP, HTTPClient, WebServer, ...) work over this interface.

The stream is polled in the background by the lwIP_Ethernet packet handler (see lwipPollingPeriod()), so no loop() call is needed.
