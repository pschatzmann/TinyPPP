Detailed Description

Portable PPP engine: LCP, PAP client and IPCP over an Arduino Stream.

The engine has no IP stack: subclasses receive IPv4 packets in onIPv4Packet() and are notified about the link state with onLinkUp() and onLinkDown(). Call process() regularly to handle input and timers.
