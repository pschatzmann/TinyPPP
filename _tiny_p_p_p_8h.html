◆ PPP_USE_NAMESPACE

#define PPP_USE_NAMESPACE   true

TinyPPP: header only PPP (Point-to-Point Protocol) networking over any Arduino Stream (USB serial, UART, ...).

  • ESP32 (all variants): uses the PPP implementation of ESP-IDF lwIP via esp_netif and integrates into the Arduino Network API (NetworkInterface, NetworkClient, NetworkServer, NetworkUDP, Network.onEvent()).
  • RP2040 / RP2350 (Earle Philhower core): uses the TinyPPP engine on a lwIP netif and integrates with WiFiClient, WiFiServer, WiFiUDP, ...
  • All other 32-bit cores, e.g. SAMD and mbed based WiFiNINA boards (Nano 33 IoT, MKR WiFi 1010, Nano RP2040 Connect), UNO R4 and the desktop (Arduino-Emulator): the TinyPPP engine with a small built-in TCP/IP stack (TCP, UDP, ICMP echo, DNS) that provides PPPClient, PPPServer and PPPUDP.

On ESP32 and RP2040 PPPClient, PPPServer and PPPUDP are aliases for the native classes, so the same sketch builds on all platforms.

Define PPP_PREFER_GENERIC (before the include or as build flag) to use the generic implementation on ESP32 and RP2040 as well.
